# Athlete Assessment Guide

## Foundation vs current form

| Dimension      | Timeframe       | What it tells you                                        |
| -------------- | --------------- | -------------------------------------------------------- |
| **Foundation** | 1-2+ years      | What the athlete has adapted to before; sport background |
| **Form**       | Last 8-12 weeks | Where they are right now; the plan's starting point      |

A former half-marathoner who has only lifted for a year rebuilds running fast. A true beginner
needs conservative run progression no matter how keen they are. Plan from **form**, set the
**rate of progression** from foundation.

## The three Hyrox athlete types

Almost everyone arrives leaning one way. Identify it from the data, then confirm by asking.

| Type                  | Data signature                                                   | Race symptom                                        | Plan emphasis                                              |
| --------------------- | ---------------------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------- |
| **Runner**            | 25+ km/week, 0-1 gym sessions, good 10k                          | Fast km 1-2, then sleds and wall balls take minutes | 2 strength sessions, heavy sled work, strength endurance   |
| **Lifter / gym**      | 3+ strength/hiit sessions, < 15 km/week running, short runs      | Strong stations, runs slow from km 4, walks late    | Run volume first: easy km, one threshold session, long run |
| **Hybrid / CrossFit** | Mix of hiit + some running, sessions short and hard, high avg HR | Goes out too hot, fades; weak aerobic base          | More Zone 2, longer continuous work, pacing discipline     |

Rule of thumb: running is ~50% of race time and the limiter for most. If the athlete cannot run
8 km continuously at an easy effort, running is the priority regardless of anything else.

## Reading wearable data

| Signal                                             | Interpretation                                                        |
| -------------------------------------------------- | --------------------------------------------------------------------- |
| Easy runs and hard runs at the same pace/HR        | No intensity distribution; everything is "medium"                     |
| Avg HR > 85% of max on most sessions               | Chronic high intensity; needs more Zone 2                             |
| Longest run < 8 km in 12 weeks                     | Not yet durable for 8 km + stations; build long run                   |
| Run pace improving at the same HR over months      | Aerobic base developing - keep going                                  |
| Resting HR trending up / HRV down (health_metrics) | Under-recovered or ill: start with a lighter week                     |
| VO2max estimate (Apple/Garmin)                     | Coarse placement only: <40 beginner, 40-50 intermediate, 50+ advanced |
| Gaps of 2+ weeks in the monthly history            | Ask why: injury, illness, travel, motivation                          |
| Strength sessions logged but < 30 min              | Likely accessories only; ask what they actually lift                  |
| Sessions titled "Hyrox" / past race activity       | Ask for the official result and splits                                |

Strength and Hyrox sessions carry duration and HR only. Never infer loads from them.

## What you must ask (the data cannot know)

**Race**

- Event, date, division (Open / Pro / Doubles / Relay), goal: finish, time target, or PR?
- Previous Hyrox results. If they have one, ask for the **station and run splits** from
  results.hyrox.com - this is the single most useful input. Slowest stations relative to
  the table in hyrox-format.md are the limiters.

**Stations and strength**

- Which stations have they done at race weight? Which feel worst?
- Can they do 100 wall balls? Largest unbroken set? At what ball weight and target height?
- Sled push/pull experience, and the surface their gym sled runs on (turf is easier than the
  race carpet for most gyms).
- Known lifts if any: squat, deadlift (rough numbers are fine), max strict pull-ups.
- Erg benchmarks: 1000 m row and 1000 m SkiErg times, or a 2 km row.

**Running**

- Recent 5k / 10k time if not in the data. Any running injuries (shin, Achilles, knee)?

**Logistics**

- Days per week and minutes per session they can really commit (ESN's reference plan assumes
  4 × 60 min; most athletes land between 4 and 6 sessions).
- Equipment: sled + turf? SkiErg? Rower? Wall ball target? Sandbag? If the gym lacks a station,
  plan substitutes from workouts.md.
- Fixed commitments, travel, preferred long-session day, training partner (for doubles).
- Injuries, health conditions, and anything a doctor has told them to avoid.

## Gap analysis

Compare current form against race demand and state each gap explicitly in the assessment:

| Demand                                | Ready when...                                               |
| ------------------------------------- | ----------------------------------------------------------- |
| 8 km of running + ~0.7 km Roxzone     | Long run ≥ 12-14 km easy; 25+ km/week for time goals        |
| 60-110 min continuous hard effort     | Regular sessions of 75-90 min; one full simulation done     |
| Sled push/pull at race weight         | 4 × 12.5 m at race weight with ≤ 30 s rests                 |
| 100 wall balls                        | 3 sets of 30-35 with short breaks, on tired legs            |
| 100 m lunges, 80 m burpee broad jumps | Completed unbroken or with planned short breaks in training |
| Running after stations                | Compromised-run pace within 10-15 s/km of fresh pace        |

## Presenting the assessment

Before designing anything, show the athlete:

1. What the data says: weekly hours and run km, sessions by type, consistency, longest run,
   estimated threshold pace and max HR, recovery markers, and which sources it came from.
2. Their athlete type and the 2-3 biggest limiters, with the evidence.
3. A realistic finish-time range (see zones.md) and whether their goal fits it.
4. The questions above that are still open.

Get their corrections, then build.
