# Periodization

## Phases

Work backwards from race day. Every plan ends with the same taper; the phases before it stretch
or shrink with the time available.

| Phase        | Share of plan | Focus                                                     | Run                                     | Strength / stations                                          | Hyrox-specific                                |
| ------------ | ------------- | --------------------------------------------------------- | --------------------------------------- | ------------------------------------------------------------ | --------------------------------------------- |
| **Base**     | 30-40%        | Aerobic base, movement quality, general strength          | Mostly Zone 2, strides, build long run  | Max/general strength 4-6 reps; learn station technique light | Short technique circuits, no race pace        |
| **Build**    | 30-35%        | Threshold, strength endurance, stations up to race weight | Threshold intervals, long run peaks     | Strength endurance 12-20 reps; race-weight sleds             | Compromised running, half simulations         |
| **Specific** | 20-25%        | Race pace, transitions, pacing, full race rehearsal       | Race-pace km repeats, shorter long run  | Maintain strength 1×/week; stations at race pace             | 1-2 full or 3/4 simulations, Roxzone practice |
| **Taper**    | 7-14 days     | Freshness                                                 | Volume −40-60%, short race-pace touches | Light, no soreness                                           | Short openers only                            |

## Plan length templates

| Weeks to race | Base | Build | Specific | Taper | Notes                                                           |
| ------------- | ---- | ----- | -------- | ----- | --------------------------------------------------------------- |
| 6             | 0-1  | 3     | 1-2      | 1     | Only for athletes already training; sharpen, do not build       |
| 8             | 2    | 3     | 2        | 1     | ESN reference length for advanced athletes: 4 × 60 min per week |
| 12            | 4    | 4     | 3        | 1     | Recommended minimum for first-timers                            |
| 16            | 5    | 5     | 4        | 2     | Good for time goals and run-limited athletes                    |
| 20-24         | 8    | 7-8   | 4-5      | 2     | Add a second base block or a mid-plan tune-up race / 10k        |

Fewer than 6 weeks: do not build fitness; practise stations, pacing and transitions, and taper.
Insert a recovery week every 3rd or 4th week (load-management.md); it counts inside its phase.

## Weekly templates

Hard sessions are marked ●. Keep at least one full rest day. Put the Hyrox-specific session on
the day the athlete has the most time and gym access (usually Saturday).

**4 sessions (ESN-style, 60 min each)**

| Day | Session                                           |
| --- | ------------------------------------------------- |
| Mon | Rest                                              |
| Tue | ● Run intervals (threshold or VO2)                |
| Wed | Strength (lower/pull focus) + erg finisher        |
| Thu | Rest or mobility                                  |
| Fri | Easy run + strides                                |
| Sat | ● Hyrox session: stations / compromised running   |
| Sun | Rest (or optional easy long run when run-limited) |

**5 sessions (standard intermediate)**

| Day | Session                                           |
| --- | ------------------------------------------------- |
| Mon | Rest                                              |
| Tue | ● Run intervals                                   |
| Wed | Strength + station technique                      |
| Thu | Easy run                                          |
| Fri | Rest or mobility                                  |
| Sat | ● Hyrox session: compromised running / simulation |
| Sun | Long easy run                                     |

**6 sessions (advanced)**

| Day | Session                                           |
| --- | ------------------------------------------------- |
| Mon | Easy run + mobility                               |
| Tue | ● Run intervals                                   |
| Wed | Strength (max → strength endurance by phase)      |
| Thu | ● Erg intervals + station strength endurance      |
| Fri | Rest                                              |
| Sat | ● Hyrox session: compromised running / simulation |
| Sun | Long easy run                                     |

**3 sessions (minimum viable)**: run intervals / strength + stations / long run with a station
block in the middle. Finishing is realistic; time goals are not.

### Adapting to the athlete type

- **Runner**: replace one easy run with a second strength/station session; keep one long run.
- **Lifter**: replace the second strength day with an easy run; long run is non-negotiable;
  keep strength at maintenance (1 heavy day).
- **Hybrid**: cap hard sessions at 3; make easy runs truly easy; lengthen continuous work.
- **Doubles**: practise station splits and "you go, I go" changeovers with the partner in the
  specific phase; both run every km, so run fitness follows the slower partner.

## Phase-by-phase progression of the key sessions

| Week type   | Run intervals                              | Strength                                   | Hyrox session                                                 | Long run    |
| ----------- | ------------------------------------------ | ------------------------------------------ | ------------------------------------------------------------- | ----------- |
| Base early  | 6-8 × 2 min steady / 1 min jog; strides    | 4 × 6 squat, deadlift, row, press          | Technique: 3 rounds light stations, full rest                 | 8-10 km     |
| Base late   | 4-5 × 5 min @ T / 90 s jog                 | 4 × 5 heavier; add carries, sled technique | EMOM / circuits at 60-70% race weight                         | 10-14 km    |
| Build early | 5 × 1 km @ T / 90 s                        | 3 × 12-15 strength endurance               | 4 × (800 m run + 1 station) at race weight                    | 12-16 km    |
| Build late  | 6 × 1 km @ T-5 s / 75 s; or 3 × 2 km       | 3 × 15-20 + sled volume                    | Half simulation: 4 km + 4 stations, race effort               | 14-18 km    |
| Specific    | 8 × 1 km @ Hyrox pace with 60-90 s station | 2 × 8 maintenance, explosive               | Full or 3/4 simulation (≥ 14 days out), then race-pace bricks | 10-12 km    |
| Taper       | 4 × 1 km @ Hyrox pace, full recovery       | 2 × 5 light and fast                       | Opener: 2 km + 3 short stations at race pace                  | 6-8 km easy |

## Taper

- **Last hard, long session** (simulation) 10-14 days before the race.
- **Final week**: volume −50-60%, frequency −1 session, intensity stays (short race-pace
  reps). No new exercises, no heavy eccentric leg work (lunges, wall balls to failure) inside
  5 days.
- **Race −2 days**: rest or 20 min easy. **Race −1 day**: 15-20 min easy jog with 3-4 strides,
  optional 2 min on each erg, then feet up.
- ESN and Hyrox both frame the taper the same way: less volume, rest, eat, hydrate - arrive at
  the start zone fresh.

## After the race

One easy week (walks, easy spins, mobility), then rebuild. Review splits against the plan's
station targets; the slowest station relative to the athlete's level is the next block's focus.
